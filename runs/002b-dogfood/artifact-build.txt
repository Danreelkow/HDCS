# RUNBOOK — sync-hermes-context.sh

## What this tool does

`sync-hermes-context.sh` performs a one-way recursive mirror of a source directory (SRC) into a destination directory (DST), using rsync semantics:

- Stale files and directories present in DST but absent from SRC are removed.
- File types, symlinks, and symlink targets are preserved (DST matches SRC structurally).
- After a real run, the tool re-verifies the mirror; a mismatch is reported and fails the run.

The tool is installed as a systemd user timer that runs the sync every 6 hours.

## Test before installing

Run a dry-run first. It prints the plan of what would be copied/removed and performs zero writes:

```
cd /workspace/hdcs/runs/001-hermes-context-timer/artifact
./sync-hermes-context.sh --dry-run
```

Nothing is created or modified by `--dry-run`.

## Install

```
cd /workspace/hdcs/runs/001-hermes-context-timer/artifact
mkdir -p ~/.local/bin ~/.config/systemd/user
install -m 755 sync-hermes-context.sh ~/.local/bin/sync-hermes-context.sh
install -m 644 hermes-context.service ~/.config/systemd/user/hermes-context.service
install -m 644 hermes-context.timer ~/.config/systemd/user/hermes-context.timer
```

## Configure

The tool reads two environment variables:

- `HERMES_CONTEXT_SRC` — source directory. Default: `/opt/data/workspace/hermes-context/`
- `HERMES_CONTEXT_DST` — destination directory. Default: `/workspace/hermes-context/`

To override them, export the variables in your shell (or in the environment of the systemd user service):

```
# example: export HERMES_CONTEXT_SRC=/data/my-context/
# example: export HERMES_CONTEXT_DST=/data/my-context-mirror/
```

Any line above starting with `# example:` is illustrative — uncomment and adjust before running. Variables left unset fall back to the production defaults. Setting a variable to an empty value is refused.

## Schedule

After installing the units, reload systemd and enable the timer:

```
systemctl --user daemon-reload
systemctl --user enable --now hermes-context.timer
```

The timer runs the sync every 6 hours.

## Verify a sync

```
cd /workspace/hdcs/runs/001-hermes-context-timer/artifact
./sync-hermes-context.sh --verify
```

- Exit code 0: DST is an exact mirror of SRC.
- Non-zero exit: a mismatch was found (see Troubleshooting, A9).

## Roll back a bad sync

If a sync wrote something bad into DST, roll back by removing the bad DST contents and re-syncing from your configured known-good source:

```
rm -rf "${HERMES_CONTEXT_DST:-/workspace/hermes-context/}"
mkdir -p "${HERMES_CONTEXT_DST:-/workspace/hermes-context/}"
"${HOME}/.local/bin/sync-hermes-context.sh"
```

These commands use whatever `HERMES_CONTEXT_SRC` and `HERMES_CONTEXT_DST` are currently configured in your environment (falling back to the defaults shown in Configure). Do not hard-code a source path here — the rollback must restore from the source you actually configured.

Note: disabling the timer alone is insufficient. The bad DST contents remain until removed and re-synced as above.

## Troubleshooting

Refusal codes printed by the tool:

| Code | Meaning |
| --- | --- |
| A9 | Mirror-mismatch findings: the destination is not an exact mirror of the source (differing files, types, or symlink targets). Reported by `--verify` or the post-sync check. |
| A12 | Path conflict: SRC and DST are the same path, one is an ancestor/descendant of the other, or a path component is a symlink tying them together. |
| A13 | Staging verification failed: a temporary staging area did not pass checks, so the destination was left untouched. |
| A14 | Staging conflicts: the staging area (e.g. influenced by `TMPDIR`) overlaps a protected path, including a set-but-empty `TMPDIR`. |
| A18 | Degenerate paths: SRC or DST is empty, `.`, or `/`. |
| A23 | Set-but-empty environment variable: `HERMES_CONTEXT_SRC` or `HERMES_CONTEXT_DST` was set to an empty value. Unset variables fall back to the production defaults. |

Other refusals describe their condition in the tool's output without a code. Any flag other than `--dry-run` or `--verify` is a usage error: the tool prints usage and exits 2.

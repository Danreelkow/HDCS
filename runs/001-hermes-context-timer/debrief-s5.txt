### Hermes Context Sync Setup

**Objective:**
Create an artifact directory that includes a script, service, timer, and README to synchronize the contents of a source directory to a workspace directory.

**Details:**
- The source directory is `/opt/data/workspace/hermes-context/`.
- The destination directory is `/workspace/hermes-context/`.
- The synchronization is one-way from the host to the workspace, with no write-back to the source directory.
- Use `rsync` with the `-a --delete` flags for the primary sync method. If `rsync` is not available, use `cp -a` or a tar pipe as a fallback.
- Perform a dry-run mode that does not make any changes.
- The systemd units will be user-level, meaning no root privileges are required.
- The script must run independently if systemd is not available.
- Ensure that the contents of the source directory are copied to the destination directory without nesting the source directory inside the destination.

**The job**
Build a standing one-way sync, SRC->DST, keeping /workspace/hermes-context an exact A9-class mirror of /opt/data/workspace/hermes-context/: contents+structure+symlinks, recursive, stale-deleted (A5, A7). The source path is /opt/data/workspace/hermes-context/ (MUST_KEEP); destination default /workspace/hermes-context/ (A1). Engine: rsync --delete; rsync may be absent, so a cp -a fallback must converge, recursively and on both sync paths, to the identical end state — a contents-of-source sync (src/->dst), no nesting (A4). One-way, host->workspace, no write-back (A2).

**Deliverables**
One artifact dir: sync-hermes-context.sh, hermes-context.service, hermes-context.timer, README.md. Scheduling: systemd user units, no root required — a systemctl --user timer firing every 6 hours via OnCalendar, ExecStart runs the script (A3). The script must also run standalone when systemd is absent. Configuration goes through HERMES_CONTEXT_SRC, HERMES_CONTEXT_DST, HERMES_CONTEXT_LOG; the env-var mechanism is mandated, and shipped defaults are production values, not scope limits (A17).

**Dry run**
--dry-run is a dry-run mode that performs no writes: no log, no DST creation, DST left byte-identical or nonexistent (A6, A16). A real run may mkdir -p DST; DST must not be required to pre-exist.

**Order law**
stage -> content-verify -> mutate (A13): stage the copy in a mktemp -d area, content-compare it against the A9 class (levels 1–3 only — contents, structure, symlinks; verify FAILs nonzero on mismatch), and only a verified copy may touch DST. Never rm -rf DST before a verified copy exists (A11). The log always lives under ~/.cache/... and never inside DST; entrypoints install at ~/.local/bin or /workspace/hdcs/bin, outside the mirrored tree (A8).

**Guards — closed list; every refusal cites its A-number (A19)**
- A11: refuse SRC==DST.
- A12: realpath-based identity/ancestry checks; refuse a symlink into SRC.
- A14/A15: a generalized owned-concrete-path guard over env-var combinations; beyond-guard combos are documented limitations, and no over-broad parent-wall refusals.
- A18: refuse empty string, '.', and '/' via component tests; refuse a DST symlink pointing outside SRC; a symlinked DST is replaced by a real tree.

**Severity and scope**
FAIL covers normal-operation defects only; exotic environments go to KNOWN_LIMITATIONS (A10). No ownership requirements beyond ordinary OS write permission; the path-law list is closed, and inventing extra scope — including ownership — is out (A19).

**no_resurrect — prior defects that must not return**
accumulate-only fallback (A5); probe-only dry-run gate (A6, A16); metadata-in-scope verify (A9); over-broad parent-wall refusals (A15); "DST must pre-exist" (A16); invented scope including ownership (A19).

**Process**
Phases: plan, scoped-build, verify, deliver. Builders are chosen dynamically; the verifier is decorrelated from them; gate is READY|NOT_READY; at most 2 fix cycles and 2 questions; roughly 60 lines, token budget an estimate. Handoff: the next seat receives state S_1 (S_0 plus this packet's delta) with a report of work done (+done), answers locked (-resolved), open items (+open), and validation (+validation).
